# TIDDOI Portfolio v2

React + JavaScript + Vite portfolio tracker.

## Deploy on Vercel
- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist

## Features
- Multiple portfolios
- Holdings and cash tracking
- Finnhub quote integration
- Average cost and profit/loss
- Buy/sell simulation
- Forecast scenarios
- Backup/restore JSON
- localStorage persistence
